# 國立清華大學醫院報告書 (第一次)

《國立清華大學醫院報告書》第弌次刊於民國十九年七月。書中記載校醫院職員、門診與住院情況、學生健康調查，以及依月份和科別整理的中英雙語來診統計。

Published in July 1930, this first report records staff, student health surveys, and hospital activity at National Tsing Hua University. It includes monthly Chinese-English statistical tables and distinguishes original blank table cells from printed zeros.

- 原刊由國立清華大學醫院編纂，1930 年刊於北平。共 36 幅，依底本分幅定位。 [館藏／原件](https://commons.wikimedia.org/w/index.php?curid=131032437)

- JSON 保留欄位及各幅來源雜湊。TXT 可連讀，TEI 可供交換與字位掛接。

- 全冊兩份影像讀稿逐頁比對與回圖，訂正 21 處。中英欄名、原印數字合計、空格及疑讀保持可定位。尚待人工全文校對。
